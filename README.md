# FFT 水印工具

一个基于网页的图片频域签名工具。上传原图和水印图后，工具会在原图 RGB 三通道的 FFT 幅度谱上叠加水印，并通过逆 FFT 生成带水印的图像。

## 功能

- **拖拽上传**：支持 JPG / PNG 格式的原图 A 和水印图 B
- **3×3 频域分析表**：展示 R / G / B 三通道的空域、幅度谱、相位谱
- **实时预览**：调整水印比例、强度、频率时，幅度谱和签名效果即时更新
- **水印叠加策略**：
  - 水印自动转灰度并二值化，只区分"黑 / 非黑"
  - 以中心对称方式嵌入频谱四角（或中心）
  - 支持调整水印大小、能量强度、频率位置
- **签名下载**：点击"签名"按钮生成并下载带水印的 PNG 图片
- **图片放大查看**：点击 3×3 表格或预览区的图片可放大查看

## 环境要求

- Python 3.8+
- 依赖包：
  - tornado >= 6.0
  - numpy >= 1.20
  - Pillow >= 9.0

## 安装

```bash
# 克隆或进入项目目录
cd fftwatermark

# 安装依赖
pip install -r requirements.txt
```

## 启动服务

```bash
python main.py
```

默认监听 **30311** 端口。启动后会输出：

```
FFT Watermark server is running at http://localhost:30311/
Press Ctrl+C to stop.
```

也可以指定其他端口：

```bash
python main.py 30313
```

## 使用说明

1. 打开浏览器访问 `http://localhost:30311/`
2. 在左侧拖入或点击上传**原图 A**
3. 在右侧拖入或点击上传**水印图 B**
4. 调整下方参数：
   - **水印比例**：控制水印 B 在频谱中的大小（0% ~ 100%）
   - **强度**：控制非黑区域幅度的放大倍数（1 ~ 10）
   - **水印频率**：控制水印位置，10 为频谱边缘，0 为频谱中心
5. 观察中间"签名预览"和下方"3×3 频域分析表"的实时变化
6. 点击**签名**按钮，在"签名结果"区域查看并下载最终图片

## 性能优化说明

为了提升实时预览的流畅度，项目做了以下优化：

- **会话缓存**：原图 A 和水印图 B 上传后缓存在服务端，调参时只传递参数，不再重复上传图片
- **请求合并**：连续快速调参时，同一时刻只执行一次计算，未完成计算期间的请求会被合并为最新一次参数
- **二进制返回**：预览接口直接返回 PNG 二进制或 multipart 数据，避免 base64 JSON 的巨大序列化开销

## 日志

日志按以下路径自动归档：

```
misc/log/YYYY/MM/DD/HH-{PID}.log
```

记录内容包括请求 URL、参数、上传文件名及大小、处理耗时、响应状态、错误信息等。

## 注意事项

- 水印图 B 建议使用**纯黑白图片**：黑色区域表示"不修改"，非黑色区域表示签名内容
- 水印放置在**高频边缘**（频率=10）时，对原图视觉影响较小
- 水印放置在**低频中心**（频率=0）时，会显著影响原图，请谨慎使用
- 刷新页面后当前会话会失效，需要重新上传图片

## 停止服务

在运行服务的终端中按 `Ctrl + C` 即可优雅退出。
